## Project overview

RxLedger is an operational pharmacy inventory app designed for community pharmacies, hospital dispensaries, and multi-branch medicine retailers. The product focuses on helping pharmacy teams track medicines by branch, batch, expiry date, barcode, supplier, NAFDAC number, and stock movement history.

The project is available on GitHub at [Zubish/RxLedger](https://github.com/Zubish/RxLedger).

## Useful features

- Branch-aware inventory so each outlet or medical site can manage its own stock while admins keep a wider account view.
- FEFO stock control that prioritizes first-expiry-first-out dispensing and helps reduce expiry waste.
- POS checkout with saved prices, receipts, sale history, and staff-linked transactions.
- Role-based access for admins, branch managers, pharmacists, inventory officers, cashiers, and viewers.
- Goods receiving workflows with supplier, invoice, batch, expiry, quantity, unit cost, and selling price validation.
- Reports for stock on hand, movement ledger, expiry risks, reorder needs, supplier activity, CSV export, and print/PDF workflows.
- Audit trails for important create, update, login, password reset, stock posting, and security-related actions.

## Implementation focus

The application is built with React, TypeScript, Vite, Vercel serverless API routes, and a Postgres-backed data model. The interface separates the marketing landing page from the authenticated workspace, so the public product story can feel clear while the main app stays dense, calm, and workflow-focused.

The design work centers on pharmacy operations: clear branch context, compact data tables, visible stock alerts, actionable dashboard cards, and controls that support repeated daily use at the counter or in the back office.

## Why this piece matters

RxLedger shows more than page styling. It demonstrates product thinking, domain research, workflow design, and front-end execution for a real operational system. The strongest part of the project is how the interface connects business rules to user actions: expiry control, staff permissions, branch switching, stock movement, and reporting all shape the experience instead of sitting behind it.
